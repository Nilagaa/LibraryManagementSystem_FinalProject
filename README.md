# 📚 Java Library Management System

A beginner-friendly **Library Management System** built with **Java** and **Swing GUI**. This project manages books and members, handles borrowing and returning of books, and uses basic data structures and algorithms like arrays, linked lists, merge sort, quick sort, linear search, and binary search to ensure efficiency.

---

## ✅ Features

- 📖 Add, remove, search, and sort books
- 👤 Add, remove, search, and sort members
- 🔎 Linear and binary search for efficient lookup
- 🗃️ Merge sort and quick sort for organizing data
- 🪟 Swing-based graphical user interface (no console)
- ⚙️ Simple fine management logic
- 🧠 Educational use of data structures and algorithms

---

## 🧠 Data Structures & Algorithms Used

- **ArrayList** for managing book and member collections
- **Merge Sort** for sorting books by title
- **Quick Sort** for sorting books by author
- **Linear Search** for keyword-based searching
- **Binary Search** for finding books by title

---

## 🖥️ Development Environment

- **Java SE 8 or higher**
- **JDK** installed
- **Swing** for GUI (built-in Java library)
- **IDE**: Eclipse, IntelliJ IDEA, or NetBeans
